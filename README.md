# Serendib Studios — HTML5 Specialist Lab
**Module:** IT22023 · Information Architecture & Web Development  
**Institution:** Horizon Campus · Faculty of IT  
**Student Index:** ITBIN-2516-0012 L. Nisal Geethanjana 

## Overview
A 2-hour sprint-based lab assignment where the goal is to act as an HTML5 
specialist at Apex Digital, auditing AI-generated code written by a junior 
developer and rebuilding it to production standards.

## What was built
- **Sprint 1 — Semantic HTML:** Fixed 7 structural errors in the AI draft 
  (wrong landmark elements, duplicate `<main>`, misused `<article>`, 
  copyright inside `<nav>`, headingless `<section>`, and more).
- **Sprint 2 — Accessible Form:** Booking form with `<fieldset>`/`<legend>`, 
  associated labels, HTML5 validation, `aria-describedby` error links, 
  and a live region for screen readers.
- **Sprint 3 — Responsive Media:** `<picture>` element with AVIF/WebP/JPEG 
  fallbacks, `srcset`/`sizes` for resolution switching, `<video>` with 
  captions track (WCAG 2.1 SC 1.2.2), and `<audio>` with format fallbacks.
- **Sprint 4 — Structured Data:** JSON-LD blocks for `Course`, `Event`, and 
  `Organization` schema types embedded in `<head>`.
- **Sprint 5 — Standards Audit:** Validated with W3C Nu HTML Checker; 
  keyboard navigation tested; accessibility habits documented.

## How to run
1. Clone or download this repository.
2. Open the project folder in **VS Code**.
3. Install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.
5. The site opens at `http://127.0.0.1:5500`.
